Attack is always toward the right. Red = defenders, blue = attackers. τ=__TAU__s, τ_run=__TAURUN__s (θ is unused — relief is continuous, not thresholded).

Colour is linear in every layer, deliberately. An earlier build applied a √ scale so midfield would show more structure; it amplified near-worthless open space into the first "valuable" band, which is exactly the illusion the value weighting exists to remove. If you want structure across the whole pitch, use Coverage only and know you are looking at space regardless of worth.
